La Régie de Regis

Toute ta prod dans une app : erreurs, sécurité, déploiements, GitHub.

Installer sur un Mac

Ouvre le Terminal et colle cette commande :

curl -fsSL https://poup-s.github.io/regie-de-regis-install/install.sh | bash

Le script :

  1. installe GitHub CLI (gh) s'il manque, sans mot de passe administrateur ;
  2. ouvre la connexion GitHub dans le navigateur si tu n'es pas déjà connecté ;
  3. télécharge la dernière version pour ton Mac et vérifie son empreinte ;
  4. l'installe dans Applications et la lance.

Les mises à jour se font ensuite depuis l'app, en un clic.

Avant de commencer

  • Un Mac Apple Silicon (M1 ou plus récent).
  • Un compte GitHub invité sur le dépôt privé poup-s/regie-de-regis : demande l'accès à Sébastien.

macOS refuse d'ouvrir l'app ?

L'app n'est pas notarisée par Apple : téléchargée depuis le navigateur, macOS la bloque (« Apple ne peut pas vérifier… »). Installe-la avec la commande ci-dessus plutôt qu'en téléchargeant le zip.

Déjà installée et bloquée ? Débloque-la :

xattr -cr "/Applications/La Régie de Regis.app"
